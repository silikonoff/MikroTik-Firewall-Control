# Изменения

## 0.2.10 — первый публичный предварительный релиз

- Выбор REST или обычного MikroTik API; HTTP/HTTPS и API/API-SSL, независимые порты.
- Старые профили сохраняют REST, маршрут, параметры и учётные данные.
- Оператор и ярлыки только включают правила. Выключение — в админке под PIN.
- Проверка актуального доступа перед следующими записями и подтверждение состояния через readback.
- Публичный экспорт исходников, документация, MIT-лицензия и CI. Тест генерации TLS-сертификата выбирает keytool для ОС запуска; логика приложения и APK сохранены.

## Предыдущие этапы

- **0.2.9:** имя MST, прежний значок щита, сохранение светлой палитры.
- **0.2.8:** фоновый опрос без пересоздания неизменившихся карточек.
- **0.2.7:** HTTP независимо от маршрута; Wi-Fi по умолчанию новых профилей.
- **0.2.5:** PIN администратора, изменение PIN и управление сессией.
- **0.2.3:** проверка переходного состояния после записи без повторения команд.
- **0.2.1:** основа приложения RouterOS 7, группы APP_STOP и прямой Ethernet.
