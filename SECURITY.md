# Безопасность

Для сообщения об уязвимости используйте **Security → Report a vulnerability** в GitHub. Не публикуйте пароли, конфигурацию сети, токены и приватные сертификаты в Issues. Исправления поддерживаются в последней опубликованной версии; срок ответа не гарантируется.

## Границы защиты

- PIN ограничивает функции интерфейса MFC. Это не замена разграничению прав RouterOS, защите телефона и контролю администратора устройства. Пользователь с доступом к ОС/отладке или учётным данным роутера может использовать другой клиент.
- Начальный PIN `0000` необходимо сменить. Пять неверных попыток дают паузу 30 секунд в текущем процессе. Ошибка чтения PIN не сбрасывает его к начальному.
- Профили зашифрованы Android Keystore/AES-GCM. Backup и перенос отключены; потеря ключа может сделать профили недоступными. Не публикуйте свои файлы данных.
- HTTP и API без TLS передают пароль открыто. HTTPS/API-SSL проверяют доверие и имя сертификата, без downgrade. Используйте отдельного пользователя и ограничение источников доступа на роутере.
- Прямые Wi-Fi/Ethernet фиксируются на выбранной сети. SYSTEM может выбрать мобильную сеть для следующей операции. Для обязательного VPN используйте системную блокировку трафика без VPN.
- Группы не атомарны. При обрыве или отзыве доступа часть правил могла измениться; уже отправленную команду нельзя отозвать. Повторы записей и автоматический rollback не выполняются. Сначала перечитайте состояние.
- Скриншоты настроек разрешены по дизайну приложения. Учитывайте видимость адресов, имён объектов и логинов при публикации снимков.

Текущий опубликованный релиз имеет предварительный статус и требует аппаратной проверки в вашей сети. Unit tests не доказывают корректность firewall-конфигурации или фактическую остановку трафика. [План проверки](docs/TESTING.md) · [Диагностика](docs/FAQ.md).
