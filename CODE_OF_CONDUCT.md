# Правила общения

Мы обсуждаем проект уважительно и по существу. Участие открыто для пользователей с любым опытом.

- Критикуйте решение и поведение программы, а не человека.
- Описывайте проблему воспроизводимо; отделяйте наблюдения от предположений.
- Не допускаются оскорбления, угрозы, дискриминация, травля и спам.
- Не публикуйте чужие личные данные, учётные записи или конфигурации без разрешения.
- Соблюдайте границы проверки: не выдавайте имитацию за тест на настоящем оборудовании.

Владелец репозитория модерирует Issues, Discussions и Pull Requests. Нарушающие эти правила сообщения могут быть скрыты или удалены, а участие — ограничено. О спорной ситуации можно сообщить владельцу через доступные средства GitHub, без раскрытия личных данных в публичном обсуждении.
