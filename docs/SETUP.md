# Настройка MikroTik для MST

Нужна RouterOS 7. Начните с безопасной тестовой группы, не перекрывающей управление роутером. MST сам не создаёт пользователей, сертификаты или firewall-правила.

## 1. Выберите интерфейс

В WinBox/WebFig откройте **IP → Services**.

- Обычный API: включите `api` (8728). Для TLS используйте `api-ssl` (8729) с серверным сертификатом.
- REST: включите `www` (80, HTTP, RouterOS 7.9+) или `www-ssl` (443, HTTPS) с сертификатом. В версиях с разделом **Web Server** разрешите REST для выбранного протокола.
- Ограничьте доступ доверенными LAN/VPN-подсетями через Available From и firewall. Не открывайте управление всему интернету.

Для HTTPS/API-SSL сертификат должен содержать SAN выбранного IP/DNS, быть действующим и доверенным Android. Для собственного CA установите его публичный сертификат в доверенные CA телефона. Проверка TLS приложением не отключается.

## 2. Создайте пользователя

**System → Users → Groups:** отдельная группа с `read`, `write`, `api`. Для REST дополнительно `rest-api`. Создайте отдельного пользователя этой группы с собственным паролем; при необходимости ограничьте Address доверенной сетью.

## 3. Подготовьте правила

В комментарии уже проверенного правила укажите, например:

```text
APP_STOP_VPN | Остановка VPN-трафика
```

Ещё одно правило с таким же префиксом попадёт в карточку VPN. `APP_STOP_GUEST` создаст отдельную карточку GUEST. Поддерживаются IPv4 Filter/NAT/Mangle/Raw. Текст после `|` показывается описанием, если он одинаков у всех правил группы.

Правила создаёт администратор под реальную топологию. Для блокировки обычно нужны корректные `drop`/`reject`, цепочки и направления. Учитывайте FastTrack, существующие соединения и порядок правил. Не помечайте правила `input`, перекрывающие управление, без понимания последствий.

## 4. Настройте телефон

**MST → ⋮ → Настройки администратора → `0000` → Добавить подключение**. Сразу смените начальный PIN. Укажите адрес без схемы/порта, учётную запись, REST/API, протокол, порт и маршрут:

| Подключение | Режим MST |
|---|---|
| Wi-Fi той же LAN | Wi-Fi напрямую |
| Доступ через готовый VPN | Системная сеть / VPN |
| USB/OTG-LAN адаптер | Ethernet |

Нужна IP-связность с роутером; для локальной LAN интернет не требуется. Телефон должен поддерживать USB-адаптер. Настройка самого VPN-сервера в эту инструкцию не входит.

## 5. Проверьте

Дождитесь карточек → включите TEST оператором → независимо проверьте `disabled` правил на MikroTik. Затем войдите в админку → «Выключить правила / восстановить трафик» → TEST → подтвердите и снова проверьте роутер.

Нет связи: проверьте маршрут, адрес, службу/порт и firewall. Ошибка входа: логин, пароль, policies и Address пользователя. Ошибка TLS: CA, SAN, срок и время телефона. После неопределённого результата сначала перечитайте состояние; не считайте группу переключённой целиком.

Официальные справочники: [API](https://manual.mikrotik.com/docs/developer-guides/api/), [REST](https://manual.mikrotik.com/docs/developer-guides/rest-api/).
