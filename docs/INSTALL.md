# Установка и обновление

[← README](../README.md) · [Настройка MikroTik →](SETUP.md)

## Первая установка

1. Скачайте **[APK 0.2.11](https://github.com/silikonoff/MikroTik-Firewall-Control/releases/download/v0.2.11/MikroTikFirewallControl-v0.2.11-debug.apk)** из репозитория `silikonoff/MikroTik-Firewall-Control`. Нужен Android 8.0+.
2. Откройте файл на телефоне. Если Android запросит разрешение на установку, разрешите её для приложения, которым вы открыли APK. После установки разрешение можно выключить.
3. Запустите **MFC**. Администратор входит через ⋮ → Настройки администратора; начальный PIN новой установки — **`0000`**.
4. Смените PIN и [настройте подключение](SETUP.md). Без выбранного роутера и доступных правил карточек групп не будет.

Текущий APK — предварительная debug-сборка. Это указано в названии файла и описании релиза.

## Обновление с прежней версии

Скачайте новый APK из **Releases** и установите поверх предыдущего приложения. Сохранение идентификатора и ключа подписи позволяет обновить приложение с прежними подключениями и PIN. Переименование MST → MFC в 0.2.11 не требует удаления старой версии.

**Не удаляйте приложение и не очищайте его данные для обычного обновления:** это удалит локальные профили и PIN. Если Android сообщает о конфликте подписи, сначала проверьте источник обоих APK — [разбор ошибки](FAQ.md).

## Какой файл скачивать

| Файл | Назначение |
|---|---|
| `MikroTikFirewallControl-v…-debug.apk` в Releases | Установка на телефон; опубликованная подпись проекта |
| `.apk.sha256` рядом | Контрольная сумма APK |
| Source code (`zip` / `tar.gz`) | Исходники для самостоятельной сборки |
| Артефакт из Actions | Проверочная CI-сборка; временная debug-подпись может отличаться |

## Проверка файла

Скачайте APK и [файл SHA256](https://github.com/silikonoff/MikroTik-Firewall-Control/releases/download/v0.2.11/MikroTikFirewallControl-v0.2.11-debug.apk.sha256). В PowerShell:

```powershell
Get-FileHash .\MikroTikFirewallControl-v0.2.11-debug.apk -Algorithm SHA256
```

Сравните значение `Hash` с контрольной суммой в `.sha256`. Регистр букв не важен. Совпадение проверяет целостность файла относительно опубликованной суммы; источник скачивания тоже имеет значение.

Подключения хранятся локально с Android Keystore; перенос профилей между телефонами и облачная синхронизация не предусмотрены. Реквизиты роутера должны отдельно оставаться у администратора.
