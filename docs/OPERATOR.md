# Памятка оператору

## Остановить трафик

1. Откройте **MFC** и проверьте название выбранного объекта/роутера.
2. Дождитесь сообщения **«Связь установлена»**.
3. Найдите нужную группу, например **VPN**, и нажмите **«Остановить трафик»**.
4. Ещё раз проверьте объект и название группы в подтверждении. Подтвердите действие и дождитесь результата.

| Состояние карточки | Что это означает |
|---|---|
| **Остановка выключена** | Все правила этой группы выключены; оператор может включить их |
| **Остановка включена** | Все правила включены; повторное включение недоступно |
| **Группа включена частично** | Состояния правил различаются; оператор может включить оставшиеся, если группа доступна |
| **Нет связи / данные последней проверки** | Показанные сведения могут быть устаревшими; команды недоступны |

**Восстановить трафик может только администратор по PIN.** На основном экране и в ярлыке такой команды нет.

## Если действие не подтверждено

Дождитесь повторной проверки. Часть правил могла уже измениться — не считайте всю группу успешно переключённой. Если сообщение повторяется или группа недоступна, обратитесь к администратору и назовите группу и текст ошибки.

При отсутствии связи проверьте подключение телефона. В меню ⋮ можно выбрать **«Обновить состояние»**. Обычная автоматическая проверка выполняется каждые 15 секунд.

Надпись на карточке показывает состояние правил роутера. Фактическое прохождение трафика зависит от настройки этих правил; его проверяет администратор.
