# Приёмка MFC 0.2.11 на смартфоне

Это план аппаратной проверки, а не отчёт о её прохождении. Используйте безопасную тестовую группу, не затрагивающую доступ к роутеру.

1. Установить поверх 0.2.9. Проверить прежний PIN, выбранный профиль, маршрут, пароль, REST-протокол и порт, неизменность палитры. Без связи команды недоступны.
2. По REST проверить чтение TEST/VPN. Оператор включает полностью выключенную или MIXED группу. Для включённой группы восстановление в основном окне и ярлыке отсутствует. Состояние независимо проверить на роутере.
3. ⋮ → Настройки администратора: неверный PIN не даёт доступа. С правильным PIN открыть «Выключить правила / восстановить трафик», выбрать группу, подтвердить. Независимо сверить disabled на роутере. Invalid допускает выключение, dynamic запрещает изменение.
4. Закрыть админку, свернуть приложение, погасить экран, повернуть экран при подтверждении/ожидании сети. Старое подтверждение не должно отправлять новые выключения после отзыва доступа. Уже отправленная команда может исполниться; при частичном результате прочитать состояние заново. При возврате доступ по правилам PIN, новый scan и новое подтверждение.
5. Под администратором изменить интерфейс профиля на «Обычный MikroTik API», API/8728. Нужны включённая служба api, разрешённая сеть и пользователь read/write/api. Подтвердить передачу без TLS. Проверить повторный запуск, чтение/включение оператором/выключение администратором и независимый результат на роутере. Отключённый www не должен мешать API. Настройку роутера выполнять отдельно с сохранением доступа.
6. Выбрать API-SSL/8729 с правильным сертификатом, доверенным CA и SAN IP/DNS. Проверить успешную работу, отказ неверному имени/CA и отсутствие попытки API без TLS. Вернуть REST и убедиться в сохранении его собственного порта/протокола.
7. Проверить оба транспорта через прямой Wi-Fi, Ethernet без интернета и SYSTEM с рабочим VPN. Для прямых маршрутов отключить соответствующую сеть при активной мобильной связи: скрытого перехода быть не должно. SYSTEM фиксирует активную сеть на операцию; следующая операция может использовать другую сеть Android, как прежде.
8. Ошибочные логин/права/порт, исчезновение сети, изменение состава группы и потеря ответа на запись: нет ложного успеха, автоматического повтора записи или переключения REST/API. Опрос основного экрана не мигает; неизменённые карточки сохраняются.

Настройка описана в SETUP.md и подсказке редактора подключения.
